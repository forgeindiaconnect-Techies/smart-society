Verification decision guide

Use the right path for every visitor type.

Valid pass / OTPMatch the guest’s name, flat and time window. Record entry and allow access only after the result confirms clearance.
Walk-in guestCreate a gate entry, call the resident through the approved contact channel and wait for a clear yes before entry.
Vendor / technicianVerify photo ID, work order, tools and destination. Confirm the approving resident or society admin.
Failed verificationDo not reuse an expired code. Keep the visitor at the gate and request a fresh approval or log an incident if required.

Before you allow entry

  • Check destination flat and visit purpose.
  • Check the pass time window has not expired.
  • Record vehicle details when applicable.

Secure handover process
  1. Confirm the flat, provider and package category before accepting the item.
  2. Record the agent name and mobile number for any stored parcel.
  3. Notify the resident; use a clear status such as handed over, stored or returned.
  4. For high-value packages, capture the resident confirmation before release.
Cash-on-delivery safeguard

Security should not collect resident cash unless the society policy explicitly permits it. Ask the resident to pay the delivery agent directly and record exceptions through an incident note.
