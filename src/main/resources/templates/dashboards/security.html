Verification decision guide

Use the right path for every visitor type.

Valid pass / OTPMatch the guest’s name, flat and time window. Record entry and allow access only after the result confirms clearance.
Walk-in guestCreate a gate entry, call the resident through the approved contact channel and wait for a clear yes before entry.
Vendor / technicianVerify photo ID, work order, tools and destination. Confirm the approving resident or society admin.
Failed verificationDo not reuse an expired code. Keep the visitor at the gate and request a fresh approval or log an incident if required.

Before you allow entry

  • Confirm guest identity matches the pass result.
  • Check destination flat and visit purpose.
  • Check the pass time window has not expired.
  • Record vehicle details when applicable.
  • Give a clear exit or return-pass instruction.

Immediate 4-Step Security Action Protocol
1
Assess & Secure the Spot Identify immediate safety hazards (fire, breach, medical emergency). Lock main vehicular gates or open emergency access lanes for first responders.
2
Notify Command Center & Society Admin Call the Society Admin hotline (+91 98440 22010). If threat is confirmed, trigger the 🚨 Emergency Panic Alert to notify all residents instantly.
3
Escort First Responders Station one security personnel at Security Gate 1 to guide incoming Police, Fire Fighters, or Ambulances directly to the affected Flat / Tower.
4
Record Gate Incident Audit Log Log exact timestamps, vehicles, flat numbers, and emergency responders in the Gate Incidents Register for audit compliance.
