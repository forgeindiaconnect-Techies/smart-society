# Frontend Directory

This folder contains all frontend assets, user interface templates, stylesheets, scripts, and media resources for the Smart Society and PropertyDirect applications.

## Folder Structure

- **`templates/`**: HTML views and dashboard templates
  - `propertydirect/`: PropertyDirect listings, apartment detail, customer, owner, builder, and admin dashboards.
  - `smartapartment/`: SmartApartment resident and society management views.
  - `dashboards/`: Role-based customer, vendor, and admin portal pages.
  - `fragments/`: Reusable navigation bars, headers, footers, and modal fragments.
  - `resident/`: Resident onboarding, self-service, and portal pages.
  - `terms/`: Terms of service, privacy policy, and pricing documentation pages.
  - `index.html`: Main landing page.

- **`static/`**: Client-side static resources
  - `propertydirect/`: PropertyDirect specific CSS, JavaScript, and asset files.
  - `smartapartment/`: SmartApartment styling, icons, and behavior scripts.
  - `shared/`: Shared typography, utilities, and vendor libraries.
  - `favicon.svg`, `robots.txt`, `sitemap.xml`: Root metadata assets.
